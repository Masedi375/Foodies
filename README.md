FOODIES WEBSITE - PART 2

CHANGELOG

1. CSS STYLING
Created an external CSS stylesheet called styles.css and linked it to all HTML pages.

2. CSS RESET
Added a CSS reset to remove default browser margins and padding and improve consistency between browsers.

3. TYPOGRAPHY
Added font family, font size, font weight, line height and letter spacing to improve the readability of the website.

4. LAYOUT
Used Flexbox for the navigation and CSS Grid for the main content and image layout.

5. VISUAL STYLING
Added colours, borders, backgrounds and box shadows to improve the appearance of the website.

6. INTERACTIVE STATES
Added hover, focus and active states to the navigation links.

7. RESPONSIVE DESIGN
Added tablet and mobile breakpoints using media queries so that the website adjusts to different screen sizes.

8. RELATIVE UNITS
Used rem, %, vw and clamp() for responsive sizing and spacing.

9. RESPONSIVE IMAGES
Added srcset and sizes attributes to images so that suitable image sizes can be selected for different screen sizes.

10. HTML CORRECTIONS
Removed inline styling and moved the styling into the external CSS stylesheet.

11. NAVIGATION
Corrected the navigation links so that they match the actual HTML filenames.
